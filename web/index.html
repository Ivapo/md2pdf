md2pdf — one markdown file in, one typeset PDF out. Everything below compiles in this page. No server.

What this adds to markdown

Twenty-two constructs are supported and eleven are shown here — the ones a reader cannot get from an ordinary markdown renderer. The README is the complete reference. Each row is the same source read two ways: what md2pdf makes of it, and what a renderer with no notion of the construct makes of it — and load it puts that source in the box at the foot of the page and compiles it here, the three refusals included.

2 · Things markdown has no way to say

These are not markers a renderer misses. They are decisions about a printed page, and a page is what markdown has never had. Frontmatter · Footnotes

Six frontmatter keys decide the look

3 · What it refuses, on purpose

A showcase that hides its refusals is selling something. Dropping or flattening content would ship a PDF that lies about its source, so the compiler names what it cannot handle and its line — and these are the sentences it prints, checked against the compiler by the same test that compiles every example above.
